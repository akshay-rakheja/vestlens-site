Set up VestLens

You run your own copy of VestLens, connected to your own accounts through your own SnapTrade key.

The code is public.

VestLens is on GitHub at github.com/akshay-rakheja/vestlens, MIT licensed. Its README has every step and option; this page is the short version.

What you'll need

  • A computer or small server that runs Docker, with Docker Compose 2.24.4 or newer. VestLens starts with Docker Compose and keeps its data in its own database.
  • Node 22 or newer and Git. Node is only for the one-time setup command that creates your sign-in password.
  • A SnapTrade Personal key, for your own accounts only. Get it at snaptrade.com/personal and check SnapTrade's pricing page for current terms before you sign up. You'll copy its client ID and consumer key into your copy's settings file.
  • Your Wealthsimple login, which you'll enter on SnapTrade's page when you connect, never in VestLens and never in a chat.
  • A public HTTPS address, for Claude or ChatGPT. Both assistants reach connectors from their own servers, so a copy that only runs on your computer works in your browser but not in chat. A tunnel or a small cloud host gives you that address.
  • Some comfort with a terminal. There's no installer.

Set it up

Run these in a real terminal (the Terminal app), not in a chat box.

  1. Download VestLens 
    git clone https://github.com/akshay-rakheja/vestlens.git
cd vestlens
cp .env.example .env
  2. Add your key

    Open .env in your editor and replace the two placeholders, SNAPTRADE_CLIENT_ID and SNAPTRADE_CONSUMER_KEY, with your SnapTrade Personal values.

  3. Choose your sign-in password

    Save a password of at least 12 characters in your password manager, then type it at this hidden prompt. .env keeps only a hash of it.

    read -rs OWNER_PASSWORD && printf '%s\n' "$OWNER_PASSWORD" | npm run setup -- --password-stdin; unset OWNER_PASSWORD
  4. Start it 
    docker compose up -d

    Open http://localhost:8080 and sign in with that password.

  5. Connect Wealthsimple

    From the dashboard, follow the link to SnapTrade's page and connect read-only. The first sync takes a few minutes.

  6. Give it an HTTPS address

    To try it today, a Cloudflare Quick Tunnel needs no account (it's for testing, and its address changes every time):

    cloudflared tunnel --url http://localhost:8080

    Put the https://….trycloudflare.com address it prints in .env as APP_BASE_URL, add TRUST_PROXY=1, and run docker compose up -d again. For an address that stays put, the README covers a named Cloudflare Tunnel and Render.

  7. Add it to your assistant

    Add <your address>/mcp as a custom connector in Claude or ChatGPT. Sign in with your VestLens password, then click Allow.

Or let a coding agent do it

Point an AI coding agent at the README. It can run everything except the parts that need you: pasting your SnapTrade key, choosing your password in your own terminal, logging in to Wealthsimple on SnapTrade's page, and clicking Allow. Never give an agent your brokerage password or two-step codes.

Before you rely on the numbers

Wealthsimple's transaction history through SnapTrade starts around April 2023, so all-time deposits and returns for older accounts are incomplete. Read the known limitations.
