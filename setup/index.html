Set up VestLens

You run your own copy of VestLens, connected to your own accounts through your own SnapTrade key.

Coming soon.

The open-source code is being prepared for release. This page will have the full steps and a link to the repository once it's published.

What you'll need

  • A computer or small server that runs Docker. VestLens starts with Docker Compose and keeps its data in its own database.
  • A SnapTrade Personal key. It's free, it's for one person, and it covers your own accounts only. You'll copy its client ID and consumer key into your copy's settings file.
  • Your Wealthsimple login, which you'll enter on SnapTrade's page when you connect, never in VestLens.
  • A public HTTPS address, for Claude or ChatGPT. Both assistants reach connectors from their own servers, so a copy that only runs on your computer works in your browser but not in chat. A tunnel or a small cloud host gives you that address.
  • Some comfort with a terminal. There's no installer.

What setup will look like

  1. Download VestLens

    Clone the repository from GitHub.

  2. Add your key

    Put your SnapTrade Personal key and a sign-in password in the settings file.

  3. Start it

    Run it with Docker Compose and sign in to your copy.

  4. Connect Wealthsimple

    Follow the link to SnapTrade's page and connect read-only.

  5. Add it to your assistant

    Add your copy's address as a custom connector in Claude or ChatGPT.

This is an outline. The exact commands will be here when the code is published.

Before you rely on the numbers

Wealthsimple's transaction history through SnapTrade starts around April 2023, so all-time deposits and returns for older accounts are incomplete. Read the known limitations.
